
# 🚀 Frontend Projects for Practice

A collection of frontend projects built to strengthen my skills in **HTML, CSS, JavaScript, and React**. Each project focuses on improving problem-solving, writing clean code, and building responsive, real-world applications from scratch.

## 📂 Projects

### 🌐 HTML & CSS
- 💼 **Portfolio Website**
  - A responsive personal portfolio showcasing my skills, projects, and contact information while practicing semantic HTML, modern CSS, and responsive design.

### 📝 HTML, CSS & JavaScript
- ✅ **To-Do App**
  - An interactive task management application that demonstrates DOM manipulation, event handling, Local Storage, and responsive user interface development.

### ⚛️ HTML,CSS & React (VITE)

- 🗺️ **Travel Journal**
   - A travel journal application for documenting and exploring places using React, with features such as Google Maps integration, drag-and-drop interactions, and interactive travel entries.

- 🍳**Recipe Finder**
   - An interactive web application that allows users to search for, filter, and save recipes using external REST APIs, focusing on complex state management, asynchronous data fetching, and user interaction.

   - Practiced advanced React patterns including fetching data with async/await, custom hooks for state management, component modularity, and saving favorite recipes to Local Storage.

**Key Features:** Real-time search filtering, dynamic recipe detail views, dietary restriction tags, and persistent "Favorite" bookmarks.

**Tech Stack:** React (Vite), CSS Modules / Tailwind CSS, Spoonacular or MealDB API, Local Storage.
Practiced React fundamentals including useState for managing application state and useEffect for handling side effects and external data.
