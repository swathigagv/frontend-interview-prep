
# HTML5: SEO Best Practices & APIs

A beginner-friendly cheat sheet for mastering SEO concepts, modern web browser features, and cracking technical interview questions.

---

## 📚 Topics

### 1. SEO Best Practices
* **Definition:** Techniques used to structure your HTML code so search engines like Google can easily crawl, understand, and rank your website higher in search results.
* **Real-Time Example:** Like putting a **bright, clear storefront sign, directory, and category labels** on a shop so people walking down the street instantly know exactly what you sell.

### 2. HTML5 APIs
* **Definition:** Built-in tools and functions provided by modern web browsers that let JavaScript interact with the user's hardware or browser features (like location, storage, or audio).
* **Real-Time Example:** Like a **smartphone's built-in toolkit**—instead of inventing a camera or GPS from scratch, your apps just ask the phone's system for permission to use them.

---

## 💼 Interview Questions

### 1. What are Semantic Tags, and how do they benefit SEO?
* **Definition:** Tags like `<article>`, `<nav>`, and `<main>` that tell search engine crawlers exactly what kind of content lives inside them, rather than generic `<div>` wrappers.
* **Real-Time Example:** Like organizing a grocery store with **clear signs reading "Dairy", "Bakery", and "Produce"** instead of putting everything into identical, unlabeled brown boxes.

### 2. What is the difference between `localStorage` and `sessionStorage`?
* **Definition:** Both are HTML5 Storage APIs; `localStorage` saves data permanently until manually deleted, while `sessionStorage` wipes data clean the moment the browser tab is closed.
* **Real-Time Example:** `localStorage` is like **writing a note in a permanent notebook**; `sessionStorage` is like writing a note on a **classroom whiteboard** that gets erased at the end of the period.

### 3. How does the HTML5 Geolocation API work, and how should it handle user privacy?
* **Definition:** A browser feature that requests a user's physical coordinates, which must always prompt an explicit "Allow or Block" permission pop-up for security.
* **Real-Time Example:** Like a **food delivery app asking for your current location**—it cannot see where you are standing until you physically tap "Allow" on your phone screen.

### 4. What is the purpose of the `alt` attribute on images for SEO and Accessibility?
* **Definition:** An HTML attribute that provides a text alternative for an image, allowing screen readers to speak it out loud and Google to index what the image represents.
* **Real-Time Example:** Like reading the **detailed text captions in a museum guidebook** when the museum's lights suddenly go out.
