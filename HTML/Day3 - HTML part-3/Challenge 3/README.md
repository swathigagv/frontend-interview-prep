# 📚 Online Course Landing Page

Build a beginner-friendly and SEO-optimized landing page for an online learning platform using only **HTML** (CSS is optional if you've already learned it).

Focus on creating a well-structured webpage using **semantic HTML**, proper **SEO best practices**, and meaningful content. Organize different sections clearly so both users and search engines can easily understand your webpage.

Try to build the project on your own first, and use the code in this repository only as a reference if you get stuck.

This project helps strengthen your understanding of semantic HTML, page structure, SEO fundamentals, accessibility, metadata, and basic HTML5 concepts—all of which are commonly discussed in frontend developer interviews.

---

## 🚀 Take It to the Next Level (Your Challenge)

Don't just copy the reference code—challenge yourself by extending the landing page with one or more of these features:

### 1. 🎓 Course Details Page
Expand your landing page by adding multiple course cards that include:
- Course title
- Instructor name
- Duration
- Skill level
- Enrollment button

Use semantic elements like `<article>`, `<section>`, and `<figure>` wherever appropriate.

---

### 2. ⭐ Student Testimonials Section
Create a testimonials section containing reviews from learners.

Challenge yourself to include:
- Student photo
- Student name
- Course completed
- Review text
- Rating using Unicode stars (★★★★★)

---

### 3. 📩 Course Enrollment Form
Add an enrollment form where users can register for a course.

Include fields such as:
- Full Name
- Email Address
- Phone Number
- Preferred Course
- Learning Mode (Online / Offline)
- Submit Button

Use proper HTML5 input types and built-in form validation.

---

### 4. 🌐 SEO Enhancement Challenge
Improve your webpage by adding:

- Meaningful `<title>`
- Meta Description
- Viewport Meta Tag
- Proper Heading Hierarchy (Only one `<h1>`)
- Descriptive Image `alt` attributes
- Semantic HTML elements
- Internal navigation links

Think like both a developer and a search engine.

---

### 💡 Bonus Challenge

If you've started learning JavaScript, try implementing **one** HTML5 API:

- 📍 Geolocation API – Display the user's current location.
- 💾 Local Storage API – Remember the visitor's name or preferred course.
- 📶 Online/Offline API – Show whether the user is connected to the internet.

---

> **Remember:** Write clean, semantic HTML first before thinking about styling. A well-structured webpage is easier to maintain, more accessible, and helps search engines understand your content better.
