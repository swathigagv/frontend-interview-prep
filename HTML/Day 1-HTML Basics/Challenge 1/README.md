# 🚀 Challenge 1: HTML Basics – The Wiki-News Deep Dive

Welcome to your first practical challenge! Now that you've mastered the core fundamentals of HTML—from document structure and semantic tags to forms and tables—it's time to put that knowledge to the test.

Your mission is to create a structured, semantic **Wikipedia-style info page** or **Newspaper Article** on a topic of your choice.

### 💡 Suggested Topic Idea:
> **"Does the Growth of AI Hunt Youngsters' Jobs? Yes or No? What People Actually Think."**
> *(Feel free to choose this topic or any other topic you are passionate about, such as tech, gaming, history, or sports!)*

---

## 🎯 Project Requirements & Checklist

Your HTML file must include the following elements from your Day 1 guide:

- [ ] **Valid Structure:** Must start with `<!DOCTYPE html>` and contain `<html>`, `<head>`, and exactly one `<body>`.
- [ ] **Semantic Layout:** Use `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>` correctly.
- [ ] **Content Hierarchy:** Use exactly **one** `<h1>` for the main headline, and break your article chapters using `<h2>` and `<h3>`.
- [ ] **Text Styling:** Use `<p>` for paragraphs, and `<br>` elements appropriately.
- [ ] **The Wiki Infobox (`<aside>`):** Create a sidebar on the right side containing an `<img>` of the topic and a `<table>` summarizing key facts (e.g., *Date, Category, Main Statistics*).
- [ ] **Interactive Elements:**
  - Standard hyperlinks (`<a>`) acting as source citations opening in a new tab (`target="_blank"`).
  - An anchor link in the footer that jumps back up to the top of the page.
- [ ] **Public Opinion Poll (Form):** A `<form>` at the bottom allowing readers to vote "Yes" or "No" on the topic, featuring properly bound `<label>` tags and a `<button>`.

---

## 🎨 The Pre-Styled CSS Solution

Because you haven't learned CSS yet, plain HTML can look raw. To make your project look like a premium, modern newspaper instantly, we are using a **Classless CSS framework called Pico.css**. 

You do **not** need to write any CSS. Simply copy and paste this exact tag inside your HTML `<head>`:

```html
<link rel="stylesheet" href="[https://cdn.jsdelivr.net/npm/@picocss/pico@2/css/pico.min.css](https://cdn.jsdelivr.net/npm/@picocss/pico@2/css/pico.min.css)">

```
