### Registration Form

Build a responsive and user-friendly registration form using only HTML, CSS, and JavaScript.

Focus on creating a clean layout, proper form structure, semantic HTML, and a good user experience. Implement client-side validation to ensure users enter valid information before submitting the form.

Try to build the project on your own first, and use the code in this repository only as a reference if you get stuck.

This project helps strengthen your understanding of HTML forms, input types, form validation, CSS styling, and basic JavaScript—topics that are frequently asked in frontend developer interviews.

## 🚀 Take It to the Next Level (Your Challenge)
Don't just copy the reference code—put your new skills to the test! Use the structure you just learned to build one of the following variations from scratch:

**1.A Clean Login Form:** Focus on minimal inputs (just Email/Username and Password), and challenge yourself to add a semantic "Remember Me" checkbox.

**2.A Job Application Form:** Move beyond text strings. Expand the form by adding a dropdown selection (<select>) for the job role, a multi-line text field (<textarea>) for a cover letter, and a file input (<input type="file">) to upload a resume.
