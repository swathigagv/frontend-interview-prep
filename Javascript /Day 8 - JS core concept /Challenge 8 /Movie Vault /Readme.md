
# 🎬 Project: The Movie Vault Challenge (Intermediate JS)

Welcome to **The Movie Vault**! This project is designed to push your JavaScript skills beyond the basics. You will build a dynamic, dark-themed movie search engine that fetches real-world data, manages a "Favorites" list in memory using closures, and updates the DOM dynamically.

---

## 🎯 The Mission

Build a web application that allows users to search for movies using a public API, view details, and save their favorites. 

### 📋 Concept Checklist (How this project uses your skills)

| Topic | How It Is Applied |
| :--- | :--- |
| **1. ES6+ Features** | Use `const`/`let`, arrow functions, template literals, and destructuring (`const { Title, Year } = movie`). |
| **2. Arrays** | Map, filter, and reduce movie data arrays returned from the API. |
| **3. Objects** | Manage complex movie data structures (handling titles, posters, ratings, and years). |
| **4. Fetch API** | Make network requests to retrieve live movie data from a public API. |
| **5. Async/Await** | Write clean, synchronous-looking asynchronous functions with robust `try...catch` error handling. |
| **6. DOM Manipulation** | Dynamically generate and inject movie cards into the HTML document. |
| **7. Events** | Handle search form submissions, button clicks, and dynamic "Favorite" toggles. |
| **8. Closures** | Create a private, secure "Favorites Manager" function that encapsulates the favorites list so it cannot be modified directly from the global window scope. |

---

## 🎨 Step 1: The UI (index.html & style.css)

Create an `index.html` , `style.css` file with a search bar, a results grid, and a sidebar for favorites.
